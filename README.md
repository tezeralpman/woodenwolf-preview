# WoodenWolf — макет-предложение

Прототип оформления сайта для столярной мастерской Дмитрия Волкова.
**Это не действующий сайт.** Действующий — [woodenwolf.ru](https://woodenwolf.ru).

Герой — проход по комнате: 600 кадров, которые проматываются скроллом. На каждой
остановке всплывают настоящие фотографии мастерской и ведут в каталог. Интерьер
сгенерирован и служит оформлением, а не портфолио.

Ниже героя — каталог на 71 фотографию по девяти разделам, калькулятор на реальных
ценах мастерской, форма заявки и контакты.

Собрано в Claude Code с плагином [roomwalk](https://github.com/tezeralpman/roomwalk).
Из поиска страница закрыта, чтобы не путать клиентов мастерской.
